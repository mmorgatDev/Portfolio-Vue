# Portfolio-Vue

This is a personal portfolio website built using Vue.js and Vite. It showcases my projects, skills, and experience in web development.

This is a revamp from the 2021 version of my portfolio, which was built using Bootstrap and simple HTML/CSS and PHP.

For this new version, I wanted to make it look much better, and also to introduce good coding practices, and everything I have learned since then in terms of CI/CD, molecular design, and more.
